# Indigo-Smart-Home-UI
# Indigo Smart Home UI Implementation

## 📝 Project Overview
This project is part of a web development assignment to replicate research-based web interfaces. I have developed HTML and CSS pages that closely resemble the output screens of the "Indigo Smart Home Automation System" as shown in the selected research paper.

## 📚 Research Paper Details
* **Title:** Indigo: Smart Home Automation System for Energy Saving
* **Authors:** Leonard Putra, et al.
* **Domain:** Smart Home / IoT / Energy Management
* **Publication:** Procedia Computer Science (2015)

## 🛠️ Implementation Details
I have implemented the following three key interfaces using HTML and CSS:

1. **Admin Panel (Fig. 6):** Manage rooms and user settings.
2. **Room Page (Fig. 7):** Monitor and control appliances (Lamps, Laptops, etc.) in specific rooms.
3. **Scheduling Page (Fig. 8):** Set timers and automated actions for various devices.

### Technologies Used:
* **HTML5:** For page structure and layout.
* **CSS3:** For styling, including the sidebar, custom buttons, and color themes.

## 📁 Folder Structure
* `/admin.html` - The main dashboard interface.
* `/room.html` - Appliance control interface.
* `/schedule.html` - Scheduling management interface.
* `/style.css` - Centralized styling for all pages.
* `/screenshots/` - Comparison images of the original paper vs. the developed UI.

## 🚀 How to Run
Simply open any of the `.html` files in a modern web browser to view the interface.
